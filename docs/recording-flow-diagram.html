    rect rgb(34, 197, 94, 0.05)
    Note over User,DDP: 阶段一：启动录音

    User->>RP: 点击录音按钮
    RP->>RP: 状态：idle → recording
    RP->>FGS: startService() 启动前台服务
    FGS->>TH: onStart(event) 创建 Isolate

    TH->>TH: 创建 UUID 录音文件夹
    TH->>REC: 初始化录音服务
    TH->>RTASR: 初始化实时 ASR 连接
    TH->>TH: 初始化天气/位置服务

    TH->>REC: 开始录音
    REC-->>TH: PCM 音频流
    TH->>REC: PCM → Opus → OGG 存储
    TH->>RTASR: PCM → WebSocket 推送
    RTASR-->>TH: ASR 中间结果
    end

    rect rgb(59, 130, 246, 0.05)
    Note over User,DDP: 阶段二：录音进行中（循环）

    loop 持续录音（最大 5 分钟）
        TH->>FGS: 推送振幅数据 (80ms)
        FGS-->>RP: onReceiveData(amplitude)
        RP->>RP: 更新波形动画

        TH->>FGS: 推送录音时长 (1s)
        FGS-->>RP: onReceiveData(seconds)
        RP->>RP: 更新计时显示

        TH->>FGS: 推送 ASR 中间文本
        FGS-->>RP: onReceiveData(text)
        RP->>RP: 更新实时文本滚动

        TH->>FGS: 推送天气/位置
        FGS-->>RP: onReceiveData(weather)
        RP->>RP: 更新天气显示
    end
    end

    rect rgb(239, 68, 68, 0.05)
    Note over User,DDP: 阶段三：停止录音

    User->>RP: 点击停止（或 5 分钟超时）
    RP->>FGS: sendDataToTask({action:'stop'})
    FGS->>TH: 收到停止指令

    TH->>REC: 停止录音
    REC-->>TH: OGG 文件写入完成
    TH->>RTASR: 关闭 WebSocket 连接

    RP->>RP: 状态：recording → idle
    RP->>DLP: 导航到日记列表页

    TH->>DB: 创建 processing 记录
    DLP->>DLP: 显示 processing 条目 (spinner)
    end

    rect rgb(139, 92, 246, 0.05)
    Note over User,DDP: 阶段四：后台异步处理（用户可自由操作）

    Note right of TH: Step 1: 上传 + ASR
    TH->>TH: 上传音频到 TOS
    TH->>ASR: Flash ASR（URL 模式，带时间戳）
    ASR-->>TH: 返回完整转录结果
    TH->>TH: 保存 transcript.json

    Note right of TH: Step 2: LLM 处理
    TH->>LLM: 调用 Doubao（润色/提炼/播报/标题）
    LLM-->>TH: 四段输出结果
    TH->>TH: 保存 llm_result.json

    Note right of TH: Step 3: 保存数据
    TH->>DB: 更新 processing → completed

    Note right of TH: Step 4: 自动归类
    TH->>TH: 匹配标签，为新日记打标签

    Note right of TH: Step 5: 通知 + TTS
    TH->>FGS: 发送完成通知
    FGS-->>DLP: 刷新列表，条目可点击
    TH->>TH: TTS 播报大纲

    TH->>FGS: 2 秒后停止前台服务
    end

    rect rgb(245, 158, 11, 0.05)
    Note over User,DDP: 阶段五：用户查看结果

    User->>DLP: 点击已完成日记条目
    DLP->>DDP: 导航到日记详情页
    DDP->>DDP: 显示完整日记内容
    User->>DDP: 可选：播放 TTS / 播放录音
    end

⚠️ 当前架构的可靠性问题总结

  • 处理后状态不透明 — 停止录音后 UI 立即 idle，处理进度只能去列表页看 spinner
  • 错误静默吞没 — ASR 断连、LLM 失败等异常，用户可能完全不知道
  • processing 卡死无兜底 — Isolate 崩溃后条目永远 processing，无超时机制
  • 已转录内容丢失 — ASR 成功但 LLM 失败时，原始转录未展示给用户
  • 前台页面切换后通讯断链 — RecordingPage 已销毁，完成事件能否到达 DiaryListPage？
  • 连续录音场景 — 前台服务单实例，A 处理 + B 录音并行的边界情况未验证
