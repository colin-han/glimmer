# 轻量润色 Prompt 设计

## 背景

当前 LLM 润色的 system prompt 指令较宽泛（"整理为通顺的日记正文"），导致 LLM 可能大幅改写原文。用户希望 AI 生成的日记尽可能尊重原始录音识别文本，仅做轻量整理。

## 目标

修改 `lib/services/llm_service.dart` 中的 system prompt，约束 LLM 的改写程度。

## 改动范围

仅修改一个文件的 system prompt 字符串，无其他代码变更。

## 新 Prompt 规则

LLM 收到语音识别文本后，应遵循以下原则：

1. **最大程度保留原文** — 不改写句子结构、不添加内容、不删除实质内容
2. **消除口语化语气助词** — 删除"嗯"、"啊"、"那个"、"就是说"、"然后呢"等无意义填充词
3. **消除重复和停顿** — 删除重复的半句、结巴等导致的不通顺
4. **按语义自然分段** — 话题转换、时间线变化处分段
5. **适当向书面语调整** — 可替换口语化词汇为对应书面表达（如"觉得"→"认为"、"挺"→"很"），保持自然
6. **生成标题** — 从内容中提炼，不超过 20 个字

## 输出格式

保持不变：`{"title": "标题", "content": "日记正文"}`，Markdown 格式。

## 不改动的部分

- JSON 解析逻辑（`_parseResult`）
- 标题提取回退逻辑（`_extractTitle`）
- `recording_page.dart` 的调用方式
- API 端点和认证方式
